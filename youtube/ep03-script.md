## [00:35 – 01:18] 챕터 1 — LDL이 뭘 하는 숫자인가

// 먼저 / LDL이 무엇인지 짧게 짚고 가겠습니다. //

그래서 **운반체**에 실려 다닙니다. //
그중 하나가 / **LDL**입니다. /
간에서 만든 콜레스테롤을 / 온몸으로 **배달하는** 쪽이에요. //
반대로 **HDL**은 / 남은 걸 다시 **회수하는** 쪽입니다. //
_배달이 많고 회수가 적으면 / 길에 쌓입니다._ //
그 길이 혈관이고, / 쌓인 게 굳으면 / 혈관이 좁아집니다. //

총콜레스테롤이 정상이어도 / LDL만 높을 수 있거든요.

## [01:18 – 02:33] 챕터 2 — 같은 175, 다른 판단

// 이제 본론입니다. //
LDL 목표치는 / **모두에게 똑같은 하나의 숫자가 아닙니다.** /
_그 사람이 얼마나 위험한 상태인가에 따라 / 목표가 달라집니다._ //
왜 그럴까요. //
LDL이 하는 일은 / 시간을 두고 혈관에 쌓이는 것입니다. /
그런데 **이미 혈관에 문제가 생긴 사람**과 /
**아직 아무 일도 없는 사람**은 / 같은 175를 견디는 여유가 다릅니다. //
그래서 위험을 이렇게 나눠서 봅니다. //
심근경색이나 뇌졸중을 **이미 겪으셨는지**. /
**당뇨**가 있으신지. /
**고혈압**이나 **흡연**은 어떠신지. /
그리고 / **가족 중에 젊은 나이에 심혈관 사고가 있었는지**. //
_이 조건들이 겹칠수록 / 목표 수치는 낮아집니다._ //
**〈 여기에 2026 지침의 위험군별 목표치 표를 화면으로 넣으세요 〉** //
그래서 / 같은 175를 들고 오셔도 //

조건이 겹치는 분은 / **바로 약을 시작하는 것을 고려**합니다. //
_숫자가 아니라 / 사람을 보는 겁니다._

// 그럼 생활습관으로 / LDL이 얼마나 내려갈까요. //
