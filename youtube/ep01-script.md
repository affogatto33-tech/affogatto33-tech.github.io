# EP.01 — 혈압 130/85, 약 먹어야 하나요?

**목표 길이** 6분 10초 · **낭독 분량** 약 1,550음절 · **속도** 330음절/분

> 발화 293초 + 호흡 표시에 따른 쉼 77초(긴 쉼 56회 · 짧은 쉼 108회) = **370초**.
> 쉼을 무시하고 읽으면 5분이 채 안 되고 정보가 흘러가 버립니다. 기호대로 쉬어 주세요.

### 녹음 기호
- `/` 짧은 쉼 (0.3초)
- `//` 긴 쉼 (0.8초) — 챕터 전환, 중요 문장 앞
- **굵게** 힘줘서 또박또박
- _(밑줄)_ 톤을 살짝 낮춰서, 차분하게

> **녹음 팁**: 챕터 단위로 끊어서 녹음하세요. 한 번에 6분을 이어 읽으면
> 뒤로 갈수록 톤이 떨어지고, 실수 하나에 전체를 다시 읽어야 합니다.

## [00:48 – 02:00] 챕터 1 — 두 숫자의 의미

// 혈압은 왜 숫자가 두 개일까요. //
심장은 / 쥐어짜고, / 풀고, / 쥐어짜고, / 풀고 / 를 반복합니다. //
**쥐어짤 때** / 혈관 벽에 걸리는 압력이 / 앞의 숫자, / **수축기 혈압**이에요. /
130에 85라면 / **130**이 여기에 해당합니다. //
그리고 심장이 **힘을 뺄 때** / 그때도 혈관에는 압력이 남아 있어요. /
그게 뒤의 숫자, / **이완기 혈압**. / 여기서는 **85**입니다. //
_뒤의 숫자를 대충 보는 분들이 많은데, / 그러면 안 됩니다._ //
이완기 혈압은 / 심장이 쉬는 동안에도 / 혈관이 얼마나 계속 눌리고 있는지를 보여줍니다. //
쉬는 시간에도 압력이 안 내려간다는 건 / **혈관이 이미 뻣뻣해지고 있다**는 신호예요. //
그래서 특히 / 젊은 층에서는 / 뒤의 숫자가 먼저 올라가는 경우가 많습니다.

## [02:00 – 03:20] 챕터 2 — 한국의 기준표

// 자, 그럼 기준표를 보겠습니다. /

그러니까 두 숫자 중 / **나쁜 쪽을 기준으로** 읽으셔야 합니다.

// 이제 130에 85로 돌아오겠습니다. /

**두세 가지만 겹쳐도 / 10 넘게 떨어집니다.** /
130이 120대로 내려가는 건 / 충분히 가능한 범위예요.

## 제목 후보

1. 혈압 130/85, 약 먹어야 하나요? (한국 기준 정확히 알려드립니다)
2. 같은 혈압인데 한국은 "전단계", 미국은 "고혈압"인 이유
3. 혈압 뒷자리를 대충 보면 안 되는 이유 | 130/85 완전 해설

## 썸네일 안

- 왼쪽: **130 / 85** 를 화면 절반 크기로. 흰 배경에 검정 숫자, 85에만 빨간 밑줄
- 오른쪽 위: "약 먹어야 하나?" (손글씨체, 노랑 형광펜 하이라이트)
- 오른쪽 아래: 혈압계 커프 사진 일부만 걸치게
- 금지: 얼굴 없음 포맷이므로 인물 클로즈업 썸네일은 쓰지 말 것 (본편과 톤이 어긋남)
