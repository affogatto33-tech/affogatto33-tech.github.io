# HeyGen 활용 계획 — Shorts 엔진

연간 결제가 이미 끝났으므로 해지 판단은 무의미합니다. **역할을 정확히 배정해서
남은 기간 동안 최대한 뽑아내는 것**이 유일한 합리적 선택입니다.

---

## 1. 왜 Shorts인가 — 지금 계획의 구멍

격주 롱폼 = **연 26편**. 이게 이 계획의 최대 약점입니다.

유튜브에서 신규 채널이 발견되는 경로는 대부분 **Shorts와 검색**입니다.
롱폼은 이미 채널을 아는 사람이 보는 포맷에 가깝습니다.
26편으로는 알고리즘에 노출될 기회 자체가 너무 적습니다.

그런데 Shorts를 직접 만들려면 편당 편집 시간이 또 듭니다.
격주 롱폼 17시간에 Shorts까지 얹으면 **지속 불가능**합니다.

**HeyGen이 정확히 이 지점을 해결합니다.** 대본만 넣으면 말하는 영상이 나오므로
Shorts의 한계 제작비가 거의 0에 수렴합니다.

| | 롱폼 | Shorts |
|---|---|---|
| 빈도 | 격주 1편 | **2주에 3개** |
| 제작 | 직접 녹음 + Kling + 편집 (17h) | HeyGen 생성 + 자막 (편당 20분) |
| 역할 | 신뢰 구축 · 상담 전환 | **발견 · 유입** |
| 연간 | 26편 | **78개** |

발행물이 연 26개에서 **104개**가 됩니다. 제작 시간은 편당 1시간 남짓 늘어납니다.

---

## 2. 역할 배정

| 작업 | 담당 | 비고 |
|---|---|---|
| **롱폼 내레이션** | **직접 녹음** | 신뢰가 핵심. 여기는 진짜 목소리 |
| **롱폼 부분 재녹음** | HeyGen 보이스 클론 | 수치·날짜 수정 시 그 문장만 재생성 |
| **Shorts 전체** | **HeyGen** | 아바타 + 보이스. 여기가 주력 |
| 영상 소스 (롱폼) | Kling + 스톡 | 변경 없음 |
| 자막 | CapCut | 변경 없음 |

**롱폼은 직접 녹음을 유지하세요.** 의원 채널에서 원장 목소리는 가장 큰 신뢰 자산이고,
6분짜리 합성 음성은 듣는 사람이 알아챕니다. 반대로 45초 Shorts는 티가 거의 안 납니다.

### 보이스 클론의 진짜 쓸모 — 부분 재녹음

EP1이 좋은 예입니다. 무료 접종 대상 연령은 절기마다 바뀝니다.
내년에 이 영상을 재활용하려면 그 한 문장만 고치면 되는데,
직접 녹음이면 **마이크 세팅부터 다시** 해야 하고 톤도 안 맞습니다.

보이스 클론이 있으면 **그 문장만 생성해서 갈아끼웁니다.**
계절 콘텐츠(독감·대상포진)를 매년 재활용할 때 이게 크게 유리합니다.

## 3. Shorts 운영 규칙

### 발행 리듬

롱폼 사이의 빈 주를 채워 **매주 뭔가 올라가게** 만듭니다.

| 시점 | 발행물 |
|---|---|
| D+0 (목) | **롱폼** |
| D+2 (토) | Shorts 1 — 롱폼의 가장 강한 훅 |
| D+6 (수) | Shorts 2 — 흔한 오해 하나 |
| D+10 (일) | Shorts 3 — 실용 팁 하나 |
| D+14 (목) | 다음 **롱폼** |

### 제작 규칙

1. **Shorts는 롱폼에서 잘라내지 마세요.** 별도로 씁니다.
   롱폼 클립을 자르면 맥락이 없어 이탈합니다.
2. **하나의 Shorts = 하나의 질문 + 하나의 답.** 45~55초.
3. **첫 2초에 질문을 던지세요.** 인사·채널소개 금지.
4. **마지막에 롱폼으로 보내세요.** "자세한 건 고정 댓글에" 형태.
5. **세로 9:16.** HeyGen에서 처음부터 세로로 생성하세요.

### 아바타 선택

세 가지 선택지가 있고, 각각 트레이드오프가 다릅니다.

| 선택 | 신뢰도 | 리스크 |
|---|---|---|
| **원장님 본인 아바타** (본인 영상으로 생성) | 가장 높음 | AI 생성 고지 필요 |
| 스톡 아바타 | 낮음 | 다른 채널과 겹침. 의료 채널엔 부적합 |
| **아바타 없이 음성만** + 자막·그래픽 | 중간 | 가장 안전. Shorts에선 흔한 포맷 |

**권장은 세 번째입니다.** "얼굴 없음" 방침을 유지하면서 HeyGen의 음성만 쓰고,
화면은 큰 자막 + 수치 그래픽으로 채웁니다. 한국 건강 Shorts에서 매우 흔한 포맷이고,
고지 부담도 가장 적습니다.

본인 아바타를 쓰고 싶으시면 4절을 반드시 읽으세요.

## 4. ⚠️ 반드시 지킬 고지 의무

### YouTube — 합성 미디어 고지

유튜브는 **실제 인물처럼 보이는 AI 생성·변조 콘텐츠**에 대해 업로드 시 고지를
요구합니다. 원장님 얼굴 아바타가 말하는 영상은 여기에 해당합니다.

- 업로드 화면의 **"변경되거나 합성된 콘텐츠"** 항목을 체크
- 시청자에게 라벨이 표시됩니다

**음성만 합성하고 얼굴이 안 나오는 경우**의 적용 범위는 정책 문언을 직접 확인하세요.
애매하면 고지하는 쪽이 안전합니다. 나중에 걸리는 것보다 낫습니다.

### 의료광고 — 매체가 달라도 규정은 같습니다

Shorts도 의료광고 규정의 적용을 받습니다. 롱폼과 동일하게:

- 치료경험담 금지
- 비급여 진료비 할인·이벤트 금지
- 타 의료기관 비교 금지
- 최상급 표현 금지

**Shorts는 짧아서 단정적으로 말하기 쉽습니다.** 이게 함정입니다.
45초 안에 "이러면 이렇습니다"로 끝내고 싶어지는데, 그러면 규정에 걸립니다.
**면책 자막을 모든 Shorts에 고정 배치**하세요.

> 일반적인 건강 정보이며 진단·치료를 대신하지 않습니다

### 신뢰 관점에서 한 가지 더

의사가 운영하는 채널에서 AI 합성 음성을 쓰는 것은 **들켰을 때 비용이 큽니다.**
댓글에서 지적당하는 순간 채널 전체의 신뢰가 흔들립니다.

그래서 이 계획은 **롱폼은 진짜 목소리, Shorts만 HeyGen**으로 나눴습니다.
Shorts 설명란에 "AI 음성으로 제작" 한 줄을 넣어두면 논란 자체가 없어집니다.
숨기지 않는 것이 가장 싼 방어입니다.

## 5. 초기 세팅 체크리스트

한 번만 하면 됩니다.

- [ ] **보이스 클론 생성** — 조용한 곳에서 원고 낭독 녹음.
      플랜별 요구 분량이 다르니 HeyGen 안내를 따를 것.
      **롱폼 대본 톤으로 읽으세요.** 학습 데이터의 톤이 그대로 나옵니다.
- [ ] 클론 음성으로 EP1 대본 한 문단 생성 → **직접 녹음본과 비교**
- [ ] 비교 결과가 만족스럽지 않으면 → Shorts에만 사용, 롱폼은 계속 직접 녹음
- [ ] 세로 9:16 템플릿 1개 저장 (자막 위치·폰트·색 고정)
- [ ] 면책 자막을 템플릿에 **박아두기** (매번 넣으면 빠뜨립니다)
- [ ] 본인 아바타를 만들 거면 → 정면 조명, 단색 배경으로 촬영

## 6. 플랜 소진 계획

연간 플랜이 남은 기간 동안 Shorts를 얼마나 만들 수 있는지 먼저 확인하세요.
크레딧이 빠듯하면 우선순위는 이 순서입니다.

1. **9·10·11편(GLP-1) Shorts** — 검색량이 가장 큽니다. 여기에 몰아쓰세요
2. 1편(독감) Shorts — 시즌이 짧아 지금 아니면 1년 뒤
3. 나머지 편 Shorts

크레딧이 남으면 **블로그 글 중 라인업에 못 넣은 것들**(변비, CRP, 지중해식 식단)을
Shorts 단독으로 만드세요. 롱폼 없이 Shorts만 있어도 됩니다.
