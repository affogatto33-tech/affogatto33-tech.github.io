# 건강 롱폼 유튜브 채널 운영 가이드

격주(2주) 업로드 · 5~7분 롱폼 · 얼굴 노출 없음 · 본인 목소리 내레이션

---

## 1. 툴 스택 결론

### HeyGen은 해지

"얼굴 없음 · 목소리만" 포맷에서 HeyGen이 파는 핵심 상품(말하는 AI 아바타 립싱크)은
쓸 일이 없다. 남는 기능(TTS·자막·번역)은 전부 무료 대체재가 있다.

| 필요 기능 | 사용할 툴 | 비용 |
|---|---|---|
| 내레이션 | **직접 녹음** (USB 콘덴서 마이크) | 무료 |
| 음성 정리 (노이즈·레벨) | Audacity 또는 CapCut | 무료 |
| 자막 | CapCut 자동자막 (한국어 정확도 양호) | 무료 |
| AI 영상 클립 | **Kling** | 유일한 유료 |
| 스톡 푸티지 | Pexels / Pixabay | 무료 |
| 편집 | CapCut 또는 DaVinci Resolve | 무료 |
| 썸네일 | Canva 무료 플랜 | 무료 |

→ **유료 구독은 Kling 하나만 유지.**
나중에 얼굴/아바타를 넣고 싶어지면 그때 HeyGen을 월 단위로 재구독하면 된다.
연간 결제로 묶여 있다면 갱신일만 미리 확인해 둘 것.

## 2. Kling 분량 함정 (제작 지속가능성의 핵심)

Kling은 클립당 5~10초다. 6분 영상 = 360초.
**전부 Kling으로 채우면 클립 6초 기준 약 60개** — 크레딧, 생성 대기, 재생성 실패율까지
감안하면 편당 수일이 걸리고 격주 페이스가 무너진다.

### 권장 화면 배분 (6분 기준)

| 소스 | 비중 | 분량 | 용도 |
|---|---|---|---|
| **Kling 생성 클립** | 30% | 약 14클립 | 오프닝 훅, 챕터 전환, 개념 시각화 |
| 무료 스톡 푸티지 | 40% | 약 2분 24초 | 일상·병원·식사 등 흔한 장면 |
| 정지 이미지 + 느린 줌 | 20% | 약 1분 12초 | 도표, 수치 비교, 기준표 |
| 텍스트 모션 | 10% | 약 36초 | 핵심 요약, 숫자 강조 |

이 비율이면 편당 Kling 작업이 반나절로 줄어 격주 유지가 가능하다.

## 4. 건강 콘텐츠 필수 안전장치

유튜브는 의료·건강 정보에 별도 정책을 적용한다. 매 영상 지킬 것:

1. **영상 내 면책 자막** — 오프닝 또는 엔딩에 고정 문구 노출
   > 이 영상은 일반적인 건강 정보이며, 의학적 진단이나 치료를 대신하지 않습니다.
   > 증상이 있다면 반드시 의료진과 상담하세요.
2. **설명란 출처 명시** — 학회 가이드라인, 질병관리청, 대한의학회 등 1차 출처 링크
3. **단정 표현 회피** — "낫습니다 / 완치됩니다" ✕ → "도움이 될 수 있습니다 / 연구에서 보고됩니다" ○
4. **특정 제품·보조제 추천 금지** — 성분 일반론까지만
5. **약 복용 지시 금지** — "약을 끊으세요 / 드세요" 는 절대 금지. "주치의와 상의" 로 종결

## 6. 블로그 글 목록 수집 (로컬 실행)

Claude Code on the web 세션은 egress proxy에 막혀 외부 웹을 읽지 못합니다.
(네이버뿐 아니라 `example.com`, `google.com` 도 동일하게 차단됩니다.)
글 목록은 **본인 컴퓨터에서** 아래를 실행해 뽑으세요.

```bash
git clone https://github.com/affogatto33-tech/affogatto33-tech.github.io.git
cd affogatto33-tech.github.io
git checkout claude/youtube-health-longform-uyjbuj

python3 youtube/tools/fetch_blog_titles.py sh_forest303
```

파이썬 표준 라이브러리만 씁니다. 설치할 패키지 없음.

### 결과물

| 파일 | 용도 |
|---|---|
