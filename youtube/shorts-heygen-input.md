# Shorts HeyGen 입력용 대본 — EP1~EP3 (9개)

**그대로 복사해서 HeyGen에 붙여넣으세요.**

원본 대본(`ep0N-shorts.md`)은 사람이 읽기 위한 것이고, 이 파일은 **TTS에 넣기 위한
발음 지시서**입니다. 같은 내용이지만 표기가 다릅니다.

## 변환 규칙

| 항목 | 원본 | HeyGen 입력 | 이유 |
|---|---|---|---|
| 마크다운 | `**굵게**` `_기울임_` | 전부 제거 | TTS가 별표를 읽어버립니다 |
| 짧은 쉼 | `/` | `,` (쉼표) | TTS는 문장부호로 쉼을 만듭니다 |
| 긴 쉼 | `//` | `.` + 줄바꿈 | |
| 숫자 | `175` | `백칠십오` | 자릿수 오독 방지 |
| 영어 약어 | `LDL` | `엘디엘` | 알파벳을 영어 발음으로 읽어버립니다 |
| 따옴표 | `"…"` | 제거 | 인용부호를 읽는 경우가 있습니다 |

### 한국어 월 표기 함정 — 반드시 확인

**6월과 10월은 불규칙입니다.** TTS가 자주 틀립니다.

| 숫자 | ✕ 잘못 | ✓ 올바름 |
|---|---|---|
| 6월 | 육월 | **유월** |
| 10월 | 십월 | **시월** |

6개월은 "육 개월"이 맞습니다. 월(月) 이름일 때만 "유월"입니다.

# EP.01 — 독감 예방접종

## S1 · 9월에 맞으면 봄에 효과 없다던데

```
독감 주사 너무 일찍 맞으면 봄에 효과가 떨어진다.
들어보셨죠. 반은 맞고 반은 틀렸습니다.

핵심은, 독감 유행이 두 번 온다는 겁니다.
십이월 초에 한 번, 이월에서 삼월에 또 한 번.

백신은, 맞고 이 주 뒤부터 효과가 시작돼서 약 육 개월 갑니다.

구월 말에 맞으면, 시월 중순부터 삼월까지.
두 유행을 다 덮습니다.

십일월 말에 맞으면, 십이월 중순부터 시작이라
일차 유행에 뒤늦게 올라탑니다.

그러니까 늦는 걸 걱정하셔야지, 이른 걸 걱정하실 게 아닙니다.

시월 안에 맞으세요.
```

## S2 · 백신 맞고 독감 걸렸다는 사람들

```
독감 주사 맞고 오히려 독감 걸렸어요.

진료실에서 자주 듣는 말입니다. 그런데 이건 백신 때문이 아닙니다.

지금 쓰는 독감 백신에는 살아 있는 바이러스가 들어 있지 않습니다.
백신이 독감을 일으키는 일은 일어나지 않습니다.

그럼 왜 아팠을까요. 두 가지입니다.

하나. 이미 감염된 상태에서 맞으셨거나.
둘. 항체가 만들어지기 전, 이 주 사이에 노출되셨거나.

백신은 맞자마자 듣는 게 아닙니다. 이 주가 필요합니다.

이 공백을 생각하면, 왜 미리 맞아야 하는지 답이 나옵니다.
```

## S3 · 맞기 전에 확인할 것 네 가지

```
독감 주사 맞으러 가시기 전에, 네 가지만 확인하세요.

하나. 오늘 컨디션.
열이 나거나 몸살 기운이 있으면 그날은 미루세요.

둘. 예전에 백신 맞고 심한 알레르기 반응이 있었다면,
접수할 때 꼭 말씀하세요.

셋. 맞고 나서 이십 분은 그 자리에 계세요.
드문 반응이지만 대부분 이 시간 안에 나타납니다.

넷. 팔이 뻐근하거나 미열이 나는 건 정상입니다.
항체가 만들어지고 있다는 신호에 가깝습니다.

다만, 고열이 이틀 넘게 가면 그땐 진료를 받으세요.
```

# EP.02 — 건강검진 결과지

## S1 · 정상B는 안심하라는 뜻이 아닙니다

> **주의**: `정상 A` → `정상 에이`, `정상 B` → `정상 비`.
> 알파벳을 그대로 두면 영어 발음으로 읽습니다.

```
건강검진 결과지에 정상 비.

정상이라고 쓰여 있으니 안심하고 덮으셨나요.

정상 비는 사실 경계라는 뜻입니다.

지금 당장 치료할 단계는 아니지만,
지켜봐야 하는 상태라는 표시예요.

많은 분들이 앞의 두 글자만 보고 넘어가십니다.
그리고 다음 검진 때 질환 의심으로 넘어와 계십니다.

정상 에이는 넘어가셔도 됩니다.
정상 비는 기억해 두세요.
질환 의심은 날짜를 잡으세요.

두 글자 차이가 몇 년을 바꿉니다.
```

## S2 · 빨간 글씨 여덟 개, 다 문제일까요

```
검진 결과지에 빨간 글씨가 여덟 개, 아홉 개.

내 몸이 여덟 군데 고장 난 걸까요. 아닙니다.

빨간 글씨는 병이 있다가 아니라,
기준 범위를 벗어났다는 표시일 뿐입니다.

그리고 이 범위는 전날 뭘 했느냐에 따라 흔들립니다.

전날 술을 드셨으면 간 수치가 올라갑니다.
심한 운동을 하셨으면 근육 효소가 올라가서 간 수치처럼 보입니다.
공복을 못 지키셨으면 혈당과 중성지방이 같이 올라갑니다.

그래서 살짝 넘은 정도라면 한 번으로 판단하지 않습니다.

개수가 아니라, 어느 줄인지가 중요합니다.
```

## S3 · 이 다섯 줄만 보세요

```
검진 결과지, 다 볼 필요 없습니다. 다섯 줄만 찾으세요.

하나. 혈압. 두 숫자 중 나쁜 쪽이 기준입니다.

둘. 공복혈당. 백을 넘으면 당화혈색소를 같이 보세요.

셋. 엘디엘 콜레스테롤. 총콜레스테롤 말고 엘디엘입니다.

넷. 간 수치. 술을 안 드시는데 높다면 오히려 더 봐야 합니다.

다섯. 신장 기능. 증상이 거의 없어서 결과지 아니면 모릅니다.

그리고 숫자 말고 영상 소견 한 줄.
엑스레이나 초음파에 코멘트가 달렸다면 꼭 확인하세요.

나머지는 그다음입니다.
```

# EP.03 — LDL 콜레스테롤

## S1 · 같은 175인데 답이 다른 이유

```
엘디엘 콜레스테롤 백칠십오.

같은 백칠십오를 들고 오셔도, 어떤 분은 바로 약을 시작하고
어떤 분은 육 개월 동안 생활습관만 하십니다.

왜 그럴까요.

엘디엘 목표치는, 모두에게 똑같은 하나의 숫자가 아니기 때문입니다.

이미 심근경색이나 뇌졸중을 겪으셨는지.
당뇨가 있으신지. 고혈압은. 담배는.
가족 중에 젊은 나이에 쓰러지신 분이 있는지.

이 조건이 겹칠수록 목표는 낮아집니다.

숫자가 아니라, 사람을 보는 겁니다.
```

## S2 · 달걀 끊으면 콜레스테롤 떨어질까요

```
콜레스테롤 높다니까 달걀부터 끊었어요.

많이 하시는 선택인데, 효율이 낮습니다.

음식으로 먹는 콜레스테롤보다
포화지방과 트랜스지방의 영향이 훨씬 큽니다.

달걀 하나를 줄이는 것보다
튀김과 가공육을 줄이는 게 훨씬 효과적이에요.

그리고 하나 더.

마른 사람은 괜찮다도 사실이 아닙니다.
체형과 엘디엘은 생각만큼 붙어 있지 않습니다.

마르셨는데 엘디엘이 높은 분, 진료실에서 드물지 않게 봅니다.
```

## S3 · 콜레스테롤 결과지 보는 순서

```
콜레스테롤 결과지 보는 순서 알려드립니다.

하나. 총콜레스테롤 말고 엘디엘을 먼저 찾으세요.
총콜레스테롤이 정상이어도 엘디엘만 높을 수 있습니다.

둘. 그 옆의 에이치디엘을 보세요.
엘디엘이 배달이면 에이치디엘은 회수입니다.

셋. 중성지방은 전날 식사에 흔들립니다.
공복을 못 지키셨다면 참고만 하세요.

넷. 그리고 내 조건을 세어보세요.
당뇨, 고혈압, 흡연, 가족력.

숫자 하나가 아니라, 이 조합이 답을 정합니다.
```

## 9월 9일 테스트할 때

이 파일의 **EP1 S1** 하나만 먼저 넣어보세요. 확인할 것 세 가지입니다.

1. **월 이름** — 시월, 유월을 제대로 읽는가
2. **길이** — 목표 44초. 35초 아래면 원본 대본의 호흡 기호(`//`)를 늘려야 합니다
3. **문장 끝 억양** — "들어보셨죠."가 질문처럼 들리는가, 평서문으로 뭉개지는가

예를 들어 "시월"을 이상하게 읽으면 `십 월`이나 `10월`로 바꿔가며 맞는 걸 찾습니다.
**정답이 정해져 있지 않고 엔진마다 다릅니다.**
