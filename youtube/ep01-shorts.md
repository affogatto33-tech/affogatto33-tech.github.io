# EP.01 파생 Shorts 3종 — 독감 예방접종

HeyGen 생성용. 세로 9:16 · 각 41~44초(실측) · 롱폼(09-17)에서 파생.

> **롱폼 대본을 잘라 쓰지 않았습니다.** 각각 독립된 글로 새로 썼습니다.
> 롱폼 클립을 자르면 앞뒤 맥락이 없어 3초 안에 이탈합니다.

## 공통 규칙

- **첫 2초에 질문.** 인사·채널 소개 금지
- 화면: 큰 자막 + 수치 그래픽. 얼굴 없음 방침 유지
- 하단 고정 자막: `일반적인 건강 정보이며 진단·치료를 대신하지 않습니다`
- 설명란 첫 줄: `AI 음성으로 제작되었습니다`
- 마지막 2초: `자세한 내용은 고정 댓글에` + 롱폼 링크

## SHORTS 1 — 타이밍 (D+2 토요일)

**제목**: 독감 주사, 9월에 맞으면 봄에 효과 없다던데

```
"독감 주사 너무 일찍 맞으면 / 봄에 효과가 떨어진다."

들어보셨죠. / 반은 맞고 반은 틀렸습니다. //

핵심은 / 독감 유행이 **두 번** 온다는 겁니다. /
12월 초에 한 번, / 2월에서 3월에 또 한 번. //

백신은 / 맞고 2주 뒤부터 효과가 시작돼서 / 약 6개월 갑니다. //

9월 말에 맞으면 / 10월 중순부터 3월까지. /
**두 유행을 다 덮습니다.** //

11월 말에 맞으면 / 12월 중순부터 시작이라 /
1차 유행에 뒤늦게 올라탑니다. //

_그러니까 늦는 걸 걱정하셔야지, / 이른 걸 걱정하실 게 아닙니다._ //

10월 안에 맞으세요.
```

**화면**: 유행 곡선 두 개(12월·3월) 위에 항체 지속 구간 막대를 겹쳐 슬라이드.
9월 접종 = 두 봉우리 다 덮음 / 11월 접종 = 첫 봉우리 놓침. **이 그림 하나가 전부입니다.**

## SHORTS 2 — 오해 (D+6 수요일)

**제목**: 백신 맞고 독감 걸렸다는 사람들, 왜 그럴까요

```
"독감 주사 맞고 / 오히려 독감 걸렸어요." //

진료실에서 자주 듣는 말입니다. / 그런데 이건 / 백신 때문이 아닙니다. //

지금 쓰는 독감 백신에는 / **살아 있는 바이러스가 들어 있지 않습니다.** /
백신이 독감을 일으키는 일은 / 일어나지 않습니다. //

그럼 왜 아팠을까요. / 두 가지입니다. //

하나. / 이미 감염된 상태에서 맞으셨거나. /
둘. / 항체가 만들어지기 전 / **2주 사이**에 노출되셨거나. //

_백신은 맞자마자 듣는 게 아닙니다._ /
2주가 필요합니다. //

이 2주를 생각하면 / 왜 미리 맞아야 하는지 / 답이 나옵니다.
```

**화면**: 접종일 → 2주 공백 구간을 빨갛게 → 항체 형성. 타임라인 하나로 끝.

## SHORTS 3 — 실용 (D+10 일요일)

**제목**: 독감 주사 맞기 전에 확인할 것 4가지

```
독감 주사 맞으러 가시기 전에 / 4가지만 확인하세요. //

**하나.** / 오늘 컨디션. /
열이 나거나 몸살 기운이 있으면 / 그날은 미루세요. //

**둘.** / 예전에 백신 맞고 / 심한 알레르기 반응이 있었다면 /
접수할 때 꼭 말씀하세요. //

**셋.** / 맞고 나서 / **20분은 그 자리에** 계세요. /
드문 반응이지만 / 대부분 이 시간 안에 나타납니다. //

**넷.** / 팔이 뻐근하거나 / 미열이 나는 건 정상입니다. /
_항체가 만들어지고 있다는 신호에 가깝습니다._ //

다만 / **고열이 이틀 넘게** 가면 / 그땐 진료를 받으세요.
```

**화면**: 숫자 1~4가 큼직하게 순차 등장. 아이콘 최소화, 글자 위주.

**셋 다 41~44초**로, 처음 잡았던 45~55초보다 짧게 나왔습니다. 그대로 갑니다.

Shorts는 짧을수록 완주율이 올라가고, 완주율이 노출을 끌어옵니다.
40초대는 오히려 유리한 구간입니다. 늘리지 마세요.

다만 HeyGen 합성 음성은 사람보다 약간 빠르게 읽는 경향이 있어
실제로는 이보다 2~4초 더 짧게 나올 수 있습니다.
**첫 개를 만들고 실제 길이를 재본 뒤**, 35초 아래로 떨어지면
호흡 기호(`//`)를 늘려 속도를 낮추세요.
