# 제작·발행 캘린더

월요일 블로그를 유지하면서, **평일 저녁만으로** 유튜브를 얹기 위한 일정입니다.
**언제 올릴지보다 언제 만들지**가 이 문서의 핵심입니다.

---

## 1. 제약 조건

| | 내용 |
|---|---|
| **블로그** | 지역타겟 포스팅 → **월요일 주 1회**로 변경 |
| **작업 가능 시간** | **평일 저녁만.** 주말 작업 불가 |
| **발행** | 예약 업로드이므로 주말 발행은 무방 (작업 아님) |

**발행과 작업을 분리해서 봐야 합니다.** 예약을 걸어두면 토·일에 나가는 것은
아무 부담이 없습니다. 제약은 오직 **"만드는 시간이 평일 저녁뿐"** 이라는 것입니다.

블로그가 주 2회에서 주 1회로 줄어든 건 큰 도움이 됩니다. 그만큼 저녁이 비었습니다.

롱폼을 3주 간격으로 늘리고, **Shorts를 매주 일요일 하나**로 고정했습니다.
날짜를 외울 필요가 없어집니다.

| 요일 | 발행 | 작업 |
|---|---|---|
| **월** | 블로그 | 블로그 작성 |
| **화** | — | **유튜브 ①** |
| **수** | — | **유튜브 ②** |
| **목** | — | **유튜브 ③** *(사이클에 따라 비움)* |

| 토 | — | — |

**월 블로그 · 금 롱폼 · 일 Shorts.** 이 셋만 기억하시면 됩니다.

3주 사이클에 평일 저녁 9칸이 생기고, 그중 **7칸만 씁니다.**
2칸은 비워 둡니다 — 이게 3주로 늘린 진짜 이유입니다.

**주 3.5시간.** 2주 간격일 때의 4.5시간에서 내려왔습니다.

어차피 피해야 했는데 그대로 맞아떨어집니다.

반면 **LDL 175(3편)와 ApoB·Lp(a)(4편)는 붙여 뒀습니다.** 한 쌍으로 설계된 편이라
떼면 4편의 훅이 약해집니다.

## 4. 연말 휴지기 — 공백이 아니라 버퍼 만드는 기간입니다

12-12 ~ 01-07 4주 동안 롱폼 발행이 없습니다. (3주 간격에서 자연히 생긴 구간입니다) 진료가 가장 바쁜 시기이고
조회수도 비수기라 쉬는 게 맞습니다. **다만 채널을 비우면 안 됩니다.**

이 4주에 할 일:

1. **GLP-1 3편(6·7·8편)을 미리 만들어 버퍼 확보.**
   1월에 3편 연속을 평일 저녁만으로 실시간 제작하는 건 불가능합니다.
   이 4주(평일 저녁 12칸, 예비분 포함)에 **대본·녹음까지** 끝내 두세요.
   1월에는 Kling·편집만 하면 됩니다.
2. **Shorts는 계속 발행.** 라인업에 못 넣은 보류 소재를 Shorts 단독으로 씁니다.
   - 변비 (블로그 39번)
   - CRP 염증 수치 팩트체크 (블로그 12번)
   - 지중해식 식단 (블로그 37번)
   - 아토피 MD 크림 (블로그 34번) — 제품 비교라 의료광고 검토 후

   롱폼 없이 Shorts만 있어도 됩니다. **HeyGen이 있으니 한계비용이 거의 0입니다.**

## 5. 3주 사이클 제작 슬롯 — 평일 저녁 7칸

한 칸 1.5시간. **9칸 중 7칸만 쓰고 2칸은 비웁니다.**

### Week 1 — 롱폼 발행 주

| 칸 | 작업 |
|---|---|
| 월 | _블로그 (다음 롱폼과 같은 주제로)_ |
| **화** | N+1편 대본 정리 — 월요일 블로그 글을 옮기는 작업 |
| **수** | N+1편 녹음 |
| **목** | Kling 프롬프트 작성 + **생성 큐 투입** |
| 금 19시 | N편 롱폼 발행 (예약분) |
| 일 20시 | Shorts 발행 (예약분) |

### Week 2 — 소재 주

| 칸 | 작업 |
|---|---|
| **화** | Kling 결과 선별·재생성 + 스톡 수집 |
| **수** | 롱폼 편집 |
| 목 | **비움** |

### Week 3 — 마감 주

| 칸 | 작업 |
|---|---|
| **화** | 편집 마무리 + 썸네일 + 설명란 |
| **수** | Shorts 3개 HeyGen 생성 + 자막 + **예약 업로드 전부** |
| 목 | **비움** |
| 금 19시 | N+1편 롱폼 발행 |

**합계 10.5시간 / 3주 = 주 3.5시간.**

### 비운 2칸을 채우지 마세요

3주로 늘린 이유가 이겁니다. 진료가 몰리는 주, 학회, 가족 일정 — 반드시 생깁니다.
**그때 쓰라고 비워둔 칸**입니다. 미리 당겨 쓰면 3주로 늘린 의미가 없어집니다.

### Kling 생성 시간이 8일로 늘었습니다

목요일 밤에 큐를 넣으면 **다음 주 화요일까지 엿새**가 있습니다.
2주 간격일 때는 나흘이었습니다. 재생성 여유가 두 배가 됐고,
어려운 클립도 여러 번 시도할 수 있습니다.

## 6. 부하를 줄이는 세 가지 — 이게 지속 가능성을 정합니다

### ① 블로그 글이 곧 대본 초안입니다

12편 중 11편이 블로그 글 기반입니다. **블로그를 쓸 때 "3주 뒤 영상"이라고
생각하고 쓰면** 대본 작성이 3시간에서 1시간으로 줍니다.

**월요일 블로그를 다음 롱폼과 같은 주제로 쓰세요.** 그러면 화요일 저녁 작업이
"쓰기"가 아니라 "옮기기"가 됩니다.

```
1주차  월  블로그 발행 (주제 X)
       화  그 글을 대본으로 정리      ← 리서치가 이미 끝나 있음
       수  녹음
       목  Kling 큐 투입
2주차  화  Kling 선별      수  편집
3주차  화  마무리          수  Shorts + 예약
       금  롱폼 발행 (주제 X)  →  블로그 글에 영상 링크 추가
```

리서치를 두 번 하지 않게 됩니다. 그리고 상호 유입까지 생깁니다.
**이 연동이 안 되면 주 3.5시간으로는 어렵습니다.** 가장 중요한 절약입니다.

### ② Kling 클립 라이브러리를 쌓으세요

고정 스타일 토큰이 전 편 동일하므로 **클립이 재사용됩니다.**

1~3편에서 33클립을 만들면 그게 자산이 됩니다. 4편부터는 편당 새로 만들 클립이
5~6개로 줄어듭니다. Kling 슬롯이 3시간에서 1.5시간으로 떨어지는 이유입니다.

`youtube/clips/` 폴더를 만들어 용도별로 정리해 두세요.
(결과지 / 혈관 / 약병 / 진료실 / 계절 / 식사 / 운동)

### ③ 버퍼 2편을 유지하세요

**이게 가장 중요합니다.** 실시간 제작은 반드시 무너집니다.
진료가 몰리는 주, 학회, 가족 일정 — 반드시 예외가 생깁니다.

지금 EP1·2·3 대본이 완성돼 있으니 **9월에 몰아서 만들어 버퍼를 쌓으세요.**
버퍼 2편이면 한 사이클을 통째로 날려도 발행이 안 끊깁니다.

## 7. 무너질 때의 규칙

지킬 순서를 미리 정해두면 흔들려도 복구됩니다.

1. **Shorts 발행은 무슨 일이 있어도 지킨다.** HeyGen이라 30분이면 됩니다.
   채널이 살아있다는 신호는 Shorts가 냅니다.
2. **롱폼이 늦으면 미루되, 건너뛰지 않는다.** 1주 밀려도 순서는 유지하세요.
   빈 자리를 다음 편으로 메우면 시즌 배치가 전부 어긋납니다.
3. **품질을 낮춰 맞추지 않는다.** 특히 의학 내용 확인은 절대 생략하지 마세요.
   의원 채널에서 틀린 정보 한 번이 조회수 100편보다 비쌉니다.
4. **버퍼가 0이 되면 한 사이클을 쉰다.** 쉬면서 2편을 다시 쌓으세요.
   무리해서 이어가다 소진되는 것보다 낫습니다.

   HeyGen이 있으니 주 30분이면 유지됩니다.
