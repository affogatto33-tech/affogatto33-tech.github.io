# 제작·발행 캘린더

블로그 주 2회를 유지하면서 유튜브를 얹기 위한 일정입니다.
**언제 올릴지보다 언제 만들지**가 이 문서의 핵심입니다.

---

## 1. 현재 부하 — 블로그가 주 2회, 화·목입니다

최근 10주 게시 이력을 세어봤습니다.

| 요일 | 게시 |
|---|---|
| **화** | 7건 |
| **목** | 6건 |
| 월 | 4건 |
| 수 | 2건 |
| 금 | 1건 |
| **토·일** | **0건** |

20건 / 9.9주 = **주 2.0회**. 화·목이 축이고 **주말은 완전히 비어 있습니다.**

이게 설계의 출발점입니다. 화·목은 건드리지 않고, 유튜브를 **수요일과 주말**에 넣습니다.

---

## 2. 발행 요일 — 롱폼을 금요일로 옮깁니다

앞서 목요일로 잡았는데 **목요일은 블로그 날**입니다. 같은 날 두 개를 내보내면
서로 노출을 갉아먹습니다.

| 요일 | 발행물 |
|---|---|
| 월 | — |
| **화** | 블로그 |
| **수** | Shorts |
| **목** | 블로그 |
| **금 19시** | **롱폼** |
| **토** | Shorts |
| **일** | Shorts |

주 5일에 무언가 나갑니다. 한국 유튜브 롱폼 소비는 금~일 저녁이 강해
금요일 19시는 시간대로도 맞습니다.

## 4. 연말 휴지기 — 공백이 아니라 버퍼 만드는 기간입니다

12-12 ~ 01-07 4주 동안 롱폼 발행이 없습니다. 진료가 가장 바쁜 시기이고
조회수도 비수기라 쉬는 게 맞습니다. **다만 채널을 비우면 안 됩니다.**

이 4주에 할 일:

1. **GLP-1 3편(8·9·10편)을 미리 만들어 버퍼 확보.**
   1월에 3편 연속을 실시간으로 만들려면 무너집니다. 12월에 대본·녹음까지 끝내세요.
2. **Shorts는 계속 발행.** 라인업에 못 넣은 보류 소재를 Shorts 단독으로 씁니다.
   - 변비 (블로그 39번)
   - CRP 염증 수치 팩트체크 (블로그 12번)
   - 지중해식 식단 (블로그 37번)
   - 아토피 MD 크림 (블로그 34번) — 제품 비교라 의료광고 검토 후

   롱폼 없이 Shorts만 있어도 됩니다. **HeyGen이 있으니 한계비용이 거의 0입니다.**

## 6. 부하를 줄이는 세 가지 — 이게 지속 가능성을 정합니다

### ① 블로그 글이 곧 대본 초안입니다

12편 중 11편이 블로그 글 기반입니다. **블로그를 쓸 때 "2주 뒤 영상"이라고
생각하고 쓰면** 대본 작성이 3시간에서 1시간으로 줍니다.

권장 흐름:

```
블로그 글 발행  →  2주 뒤  →  같은 주제 롱폼 발행
                              (블로그 글에 영상 링크 추가)
```

상호 유입까지 생깁니다. 블로그 독자가 유튜브로, 유튜브 시청자가 블로그로.

### ② Kling 클립 라이브러리를 쌓으세요

고정 스타일 토큰이 전 편 동일하므로 **클립이 재사용됩니다.**

1~3편에서 33클립을 만들면 그게 자산이 됩니다. 4편부터는 편당 새로 만들 클립이
5~6개로 줄어듭니다. Kling 슬롯이 3시간에서 1.5시간으로 떨어지는 이유입니다.

`youtube/clips/` 폴더를 만들어 용도별로 정리해 두세요.
(결과지 / 혈관 / 약병 / 진료실 / 계절 / 식사 / 운동)

### ③ 버퍼 2편을 유지하세요

**이게 가장 중요합니다.** 실시간 제작은 반드시 무너집니다.
진료가 몰리는 주, 학회, 가족 일정 — 2주에 한 번은 예외가 생깁니다.

지금 EP1·2·3 대본이 완성돼 있으니 **9월에 몰아서 만들어 버퍼를 쌓으세요.**
버퍼 2편이면 한 사이클을 통째로 날려도 발행이 안 끊깁니다.

## 7. 무너질 때의 규칙

지킬 순서를 미리 정해두면 흔들려도 복구됩니다.

1. **Shorts 발행은 무슨 일이 있어도 지킨다.** HeyGen이라 30분이면 됩니다.
   채널이 살아있다는 신호는 Shorts가 냅니다.
2. **롱폼이 늦으면 미루되, 건너뛰지 않는다.** 1주 밀려도 순서는 유지하세요.
   빈 자리를 다음 편으로 메우면 시즌 배치가 전부 어긋납니다.
3. **품질을 낮춰 맞추지 않는다.** 특히 의학 내용 확인은 절대 생략하지 마세요.
   의원 채널에서 틀린 정보 한 번이 조회수 100편보다 비쌉니다.
4. **버퍼가 0이 되면 한 사이클을 쉰다.** 쉬면서 2편을 다시 쌓으세요.
   무리해서 이어가다 소진되는 것보다 낫습니다.
