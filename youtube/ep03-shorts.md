## SHORTS 1 — 강한 주장 (D+2 토)

**제목**: 같은 콜레스테롤 175인데 답이 다른 이유

```
LDL 콜레스테롤 **175**. //

같은 175를 들고 오셔도 / 어떤 분은 바로 약을 시작하고, /
어떤 분은 6개월 동안 / 생활습관만 하십니다. //

_왜 그럴까요._ //

LDL 목표치는 / **모두에게 똑같은 하나의 숫자가 아니기 때문**입니다. //

이미 심근경색이나 뇌졸중을 겪으셨는지. /
당뇨가 있으신지. / 고혈압은. / 담배는. /
가족 중에 / 젊은 나이에 쓰러지신 분이 있는지. //

_이 조건이 겹칠수록 / 목표는 낮아집니다._ //

**숫자가 아니라 / 사람을 보는 겁니다.**
```

**화면**: 175 하나에서 화살표 두 개로 갈라짐 → 왼쪽 "생활습관" / 오른쪽 "약".

## SHORTS 2 — 오해 깨기 (D+6 수)

**제목**: 달걀 끊으면 콜레스테롤 떨어질까요

```
"콜레스테롤 높다니까 / 달걀부터 끊었어요." //

_많이 하시는 선택인데, / 효율이 낮습니다._ //

음식으로 먹는 콜레스테롤보다 /
**포화지방과 트랜스지방**의 영향이 훨씬 큽니다. //

달걀 하나를 줄이는 것보다 /
**튀김과 가공육**을 줄이는 게 / 훨씬 효과적이에요. //

그리고 하나 더. //

"마른 사람은 괜찮다"도 / 사실이 아닙니다. /
체형과 LDL은 / 생각만큼 붙어 있지 않습니다. //

_마르셨는데 LDL이 높은 분, / 진료실에서 드물지 않게 봅니다._
```

**화면**: 달걀에 X → 튀김·가공육으로 화살표 이동.

## SHORTS 3 — 체크리스트 (D+10 일)

**제목**: 콜레스테롤 결과지, 이 순서로 보세요

```
콜레스테롤 결과지 / 보는 순서 알려드립니다. //

**하나.** / 총콜레스테롤 말고 / **LDL**을 먼저 찾으세요. /
총콜레스테롤이 정상이어도 / LDL만 높을 수 있습니다. //

**둘.** / 그 옆의 **HDL**을 보세요. /
LDL이 배달이면 / HDL은 회수입니다. //

**셋.** / **중성지방**은 전날 식사에 흔들립니다. /
공복을 못 지키셨다면 / 참고만 하세요. //

**넷.** / 그리고 **내 조건**을 세어보세요. /
당뇨, / 고혈압, / 흡연, / 가족력. //

_숫자 하나가 아니라 / 이 조합이 답을 정합니다._
```

**화면**: 결과지 지질 항목에서 LDL → HDL → 중성지방 순차 하이라이트.
