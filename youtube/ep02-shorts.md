## SHORTS 1 — 강한 주장 (D+2 토)

**제목**: '정상B'는 안심하라는 뜻이 아닙니다

```
건강검진 결과지에 / **정상 B**. //

'정상'이라고 쓰여 있으니 / 안심하고 덮으셨나요. //

_정상 B는 / 사실 '경계'라는 뜻입니다._ //

지금 당장 치료할 단계는 아니지만, /
**지켜봐야 하는 상태**라는 표시예요. //

많은 분들이 / 앞의 두 글자만 보고 넘어가십니다. /
그리고 다음 검진 때 / 질환 의심으로 넘어와 계십니다. //

정상 A는 넘어가셔도 됩니다. /
**정상 B는 기억해 두세요.** /
질환 의심은 / 날짜를 잡으세요. //

_두 글자 차이가 / 몇 년을 바꿉니다._
```

**화면**: 정상A / **정상B** / 질환의심 / 유질환자 네 칸. 정상B만 남기고 나머지 회색.

## SHORTS 2 — 오해 깨기 (D+6 수)

**제목**: 빨간 글씨 여덟 개, 다 문제일까요

```
검진 결과지에 / 빨간 글씨가 / 여덟 개, 아홉 개. //

_내 몸이 여덟 군데 고장 난 걸까요._ / **아닙니다.** //

빨간 글씨는 / "병이 있다"가 아니라 /
"기준 범위를 벗어났다"는 표시일 뿐입니다. //

그리고 이 범위는 / 전날 뭘 했느냐에 따라 흔들립니다. //

전날 술을 드셨으면 / 간 수치가 올라갑니다. /
심한 운동을 하셨으면 / 근육 효소가 올라가서 / 간 수치처럼 보입니다. /
공복을 못 지키셨으면 / 혈당과 중성지방이 같이 올라갑니다. //

_그래서 살짝 넘은 정도라면 / 한 번으로 판단하지 않습니다._ //

**개수가 아니라 / 어느 줄인지가 중요합니다.**
```

**화면**: 빨간 글씨 여러 개 → 하나씩 회색으로 꺼지며 몇 개만 남음.

## SHORTS 3 — 체크리스트 (D+10 일)

**제목**: 검진 결과지에서 이 다섯 줄만 보세요

```
검진 결과지, / 다 볼 필요 없습니다. / **다섯 줄만 찾으세요.** //

**하나. 혈압.** / 두 숫자 중 / 나쁜 쪽이 기준입니다. //
**둘. 공복혈당.** / 100을 넘으면 / 당화혈색소를 같이 보세요. //
**셋. LDL 콜레스테롤.** / 총콜레스테롤 말고 / **LDL**입니다. //
**넷. 간 수치.** / _술을 안 드시는데 높다면 / 오히려 더 봐야 합니다._ //
**다섯. 신장 기능.** / 증상이 거의 없어서 / 결과지 아니면 모릅니다. //

그리고 숫자 말고 / **영상 소견 한 줄.** /
엑스레이나 초음파에 / 코멘트가 달렸다면 / 꼭 확인하세요. //

_나머지는 그다음입니다._
```

**화면**: 1~5 숫자가 큼직하게 순차 등장. 마지막에 다섯 줄 한 화면에 모으기.
